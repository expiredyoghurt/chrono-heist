Chrono Heist

The Anachronist Files

History has been tampered with. Someone calling themselves The Anachronist is raiding the timeline — stealing legacy artifacts from the past, and dropping objects that don't belong into eras that never should have seen them. The Chrono Agency needs a new field agent to chase the trail across ten civilizations. Every case you crack — or don't — teaches you something about how that world shaped the one you live in now.

Field Manual

Travel to each era on the map and investigate the case. Each case has three decisions — choose carefully, but don't worry about "losing": whether you crack the case or the trail goes cold, you'll always recover the full case file, learn the civilization's story, and see how its legacy lives on today. Successful cases add the recovered artifact to your Evidence Bag and earn full points. Missed cases still earn partial points. Your name, score, and evidence bag are saved to the leaderboard.

Admin: Seed Map Data

One-time setup step, done entirely in this browser — no terminal needed. This downloads the world coastline data and stores it in your own MAP_KV namespace via the deployed Worker/Function, so the situation map no longer depends on any third-party CDN. You only need to do this once per deployment. Requires the MAP_ADMIN_KEY you set in the Cloudflare dashboard.

Admin: AI Backend Status

Checks which AI backend(s) are actually connected on the deployed site — no API calls are made, this just reports which bindings/secrets the Worker can currently see. Use this first if the Chrono Archivist or Field Quiz aren't working.
